# Udemy Clone 🎓

A simple online learning website inspired by Udemy.

## Technologies
- HTML5
- CSS3

## Features
- Navigation bar
- Search bar
- Course cards
- Course categories
- Responsive design

## How to Run
1. Download the project.
2. Open in VS Code.
3. Run `index.html` using Live Server.
